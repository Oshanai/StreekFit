## 0. Продукт и философия

Приложение, где движение (отжимания, приседания, шаги, бег) верифицируется камерой и GPS, сводится в один **счёт дня**, кормит **стрик** и **лидерборд города / друзей**, и шерится в **сторис** для виральной петли. Бесплатно — трекинг себя. По подписке — соревнование, карта трека, премиум-рамки.

**Философия (не нарушать при проектировании):**
- Комфорт, а не насилие. Цели адаптивные, растут постепенно. Пользователь не должен бросить на 2-й день.
- Долгосрочная атлетическая адаптация через прогрессивную нагрузку + постоянство + отдых.
- Три языка с первого дня: казахский (kk), русский (ru), английский (en).
- Все переходы — плавные и красивые (Reanimated). Смена языка — с анимацией, не резким рефрешем.

## 3. Фаза 2 — Счётчик движения камерой (ядро, главный технический риск)

### 3.1 Камера и распознавание позы
- [x] `react-native-vision-camera` — **v5.1 (Nitro)** + `react-native-vision-camera-worklets` на общем `react-native-worklets` (том же, что у Reanimated 4)
- [x] Pose-модель: **MoveNet SinglePose Lightning int8** (tflite, 2.9 МБ в `assets/models/`) через `react-native-fast-tflite` v3; маппинг 17 COCO-точек → BlazePose-слоты (`movenet.ts`)
- [x] **Обработка кадров на worklet-потоке**: `useFrameOutput` → letterbox-ресайз в тензор (`frameTensor.ts`, аспект сохраняется — углы не искажаются) → `runSync` → FSM; в JS уходят только агрегаты через shared values, HUD поллит 4 Гц
- [x] Лёгкий оверлей скелета (`SkeletonOverlay.tsx`: полилиния + суставы лучшей стороны, Reanimated animatedProps — без ре-рендера на кадр)
> Код готов и собирается; точность подсчёта и отсутствие фризов проверяются на устройстве (dev client, критерий готовности фазы ниже).

### 3.2 Правила подсчёта (зашить точно)
- [x] **Повтор засчитывается только при полной амплитуде:** (движок `src/features/movement/`, 30 тестов)
  - Отжимание: локоть вниз ≤ 90°, вверх ≥ 160°, корпус горизонтально
  - Приседание: бедро до параллели (колено ~≤ 100°), полное вставание
- [x] Гистерезис (два порога), чтобы дрожание не давало двойных повторов (+ защита от фликеров позы и «телепортов» в глубину)
- [x] Неполный повтор мягко не засчитывается («не в счёт»), без наказания (+ фидбек nearLockout при недожиме)
- [x] **Подход закрыт** при достижении персональной цели по повторам; минимальный пол для регистрации подхода — 5 валидных повторов (`setTracker.ts`: авто-закрытие по цели; ручной стоп <5 — мягко «не в счёт»)
- [x] Таймер отдыха между подходами, подходы можно раскидать по дню (отдых советующий, не блокирует; часовые паузы ничего не ломают)
- [x] Санити-чек по темпу (нереально быстрые — отсекать; отказ двигает якорь темпа — «баунс-фарм» невозможен)
- [x] Работа офлайн: сессия считается без сети, синкается позже (`sessionQueue.ts`: очередь в AsyncStorage, идемпотентный upsert по клиентскому UUID; `useSessionSync` — синк при входе и возврате в foreground)

**Критерий готовности:** реальные отжимания/приседания считаются точно и без фризов; неполные не засчитываются; подходы и отдых работают; офлайн ок.

## 6. Фаза 5 — Счёт дня, стрик, прогрессия

### 6.1 Счёт дня
- [x] Единый счёт: отжимания + приседания + шаги (+ бег при Фазе 4) → одно число (`dayScore.ts`: повтор=10, 10 шагов=1, минута бега=15)
- [x] Прогресс-бар дневной цели (цель из user_targets: 3 подхода × цели + шаги)

### 6.2 Стрик
- [x] **День стрика = 3 подхода отжиманий + 3 подхода приседаний + шаги** (цели персональные) — `streak.ts` evaluateDay, статус пишется в `daily_scores.status`
- [x] **Дни отдыха НЕ рвут стрик**: один день отдыха между закрытыми днями допустим, два подряд — обнуляют (`computeStreak`, грация в тестах)
- [x] «Лёгкий день» — закрывается только шагами (status='light', держит цепь)
- [ ] Заморозка стрика (1–2 спасения) — платное или за друга (Фаза 9, монетизация)

### 6.3 Прогрессивная нагрузка (атлетическое тело на долгосроке)
- [x] Стартовые цели — из калибровочного теста
- [x] Справился 3 полных дня подряд → цели +1 (`progression.ts`, guard: не чаще раза в день)
- [x] Периодический deload: каждое 4-е изменение — −15% (пол 5) — волна вместо потолка
- [x] Никакого негативного тона; мягкие баннеры («восстановление тоже часть плана»)

**Критерий готовности:** всё сходится в одно число; стрик считается по формуле и переживает дни отдыха; цели растут постепенно и комфортно.
