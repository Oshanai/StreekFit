## 0. Продукт и философия

Приложение, где движение (отжимания, приседания, шаги, бег) верифицируется камерой и GPS, сводится в один **счёт дня**, кормит **стрик** и **лидерборд города / друзей**, и шерится в **сторис** для виральной петли. Бесплатно — трекинг себя. По подписке — соревнование, карта трека, премиум-рамки.

**Философия (не нарушать при проектировании):**
- Комфорт, а не насилие. Цели адаптивные, растут постепенно. Пользователь не должен бросить на 2-й день.
- Долгосрочная атлетическая адаптация через прогрессивную нагрузку + постоянство + отдых.
- Три языка с первого дня: казахский (kk), русский (ru), английский (en).
- Все переходы — плавные и красивые (Reanimated). Смена языка — с анимацией, не резким рефрешем.

## 3. Фаза 2 — Счётчик движения камерой (ядро, главный технический риск)

### 3.1 Камера и распознавание позы
- [ ] `react-native-vision-camera` (v3+, frame processors)
- [ ] Pose-модель: MediaPipe BlazePose / MoveNet (плагин или QuickPose SDK)
- [ ] **Обработка кадров на нативном/worklet-потоке, НЕ через JS-мост** (см. раздел 11)
- [ ] Лёгкий оверлей скелета

### 3.2 Правила подсчёта (зашить точно)
- [ ] **Повтор засчитывается только при полной амплитуде:**
  - Отжимание: локоть вниз ≤ 90°, вверх ≥ 160°, корпус горизонтально
  - Приседание: бедро до параллели (колено ~≤ 100°), полное вставание
- [ ] Гистерезис (два порога), чтобы дрожание не давало двойных повторов
- [ ] Неполный повтор мягко не засчитывается («не в счёт»), без наказания
- [ ] **Подход закрыт** при достижении персональной цели по повторам; минимальный пол для регистрации подхода — 5 валидных повторов
- [ ] Таймер отдыха между подходами, подходы можно раскидать по дню
- [ ] Санити-чек по темпу (нереально быстрые — отсекать)
- [ ] Работа офлайн: сессия считается без сети, синкается позже

**Критерий готовности:** реальные отжимания/приседания считаются точно и без фризов; неполные не засчитываются; подходы и отдых работают; офлайн ок.

## 6. Фаза 5 — Счёт дня, стрик, прогрессия

### 6.1 Счёт дня
- [ ] Единый счёт: отжимания + приседания + шаги + бег → одно число
- [ ] Прогресс-бар дневной цели

### 6.2 Стрик
- [ ] **День стрика = 3 подхода отжиманий + 3 подхода приседаний + 7000 шагов** (цели персональные)
- [ ] **Плановые дни отдыха НЕ рвут стрик** (восстановление обязательно)
- [ ] «Лёгкий день» — можно закрыть только шагами
- [ ] Заморозка стрика (1–2 спасения) — платное или за приглашённого друга

### 6.3 Прогрессивная нагрузка (атлетическое тело на долгосроке)
- [ ] Стартовые цели — из калибровочного теста
- [ ] Справился несколько дней подряд → цель мягко растёт (+1–2 повтора)
- [ ] Периодический deload (снижение нагрузки) для устойчивости
- [ ] Никакого негативного тона; мягкие напоминания, а не давление

**Критерий готовности:** всё сходится в одно число; стрик считается по формуле и переживает дни отдыха; цели растут постепенно и комфортно.

## Риски и зависимости
- **Камера-фризы** — главный риск, решается потоками (11.1)
- **Правила сторов по оплате** — цифровая подписка на iOS требует IAP; Kaspi/веб — сверху
- **GPS-спуфинг** — для бега; хватает театра, пока нет денег на кону
- **Instagram Stories share** — зависит от их SDK; проверить заранее
- **Локализация** — вёрстка не должна ломаться на длинных казахских/английских строках
- **Консистентность ассетов** — 30 бейджей должны выглядеть коллекцией
